# แผนลงมือ MONO V6

**Goal:** ปรับต้นแบบตามแผน V6 ให้ซื้อเสื้อตรง ซื้อ Kit ใช้โค้ด และซื้อซ้ำได้ครบ
**Architecture:** ใช้ catalog กลาง, rules แบบ pure, store v2 ย้ายจาก v1 และ views/hash router เดิม
**Tech Stack:** HTML/CSS/JavaScript, SVG/WebP ใน repo ไม่มี dependency ของเว็บ
**Spec:** เอกสารบนเครื่อง `coursework/team/MONO-V6-prototype-plan.md` (ไม่เผยแพร่ข้อมูลวิชา)

## ข้อจำกัดและการตัดสินใจ
- เงินจำนวนเต็มสตางค์ ที่อยู่สมมติ ค่าส่งศูนย์ ไม่มี API หรือเซิร์ฟเวอร์
- หนึ่งโค้ดต่อรายการซื้อเสื้อ ไม่มีขั้นต่ำ ไม่กำหนดวันหมดอายุหรือการซ้อนโค้ด
- สีขาว ภาพและตารางแต่ละรุ่น/ล็อตเป็นข้อมูลสาธิตจนกว่าจะได้ข้อมูลโรงงาน
- ทำงานใน checkout ที่ผู้ใช้ระบุ ใช้คำสั่งทดสอบจากเครื่อง ไม่มีแพ็กเกจเพิ่ม

## Review Focus
- ประวัติสินค้าที่เลิกขายต้องอ่าน snapshot ได้โดยไม่ resolve กับ catalog ใหม่
- โค้ดที่ใช้จากอีกแท็บต้องไม่ใช้ซ้ำ และกดยืนยันซ้ำต้องได้ใบเดิม
- รหัส 0, 2.1, 2.2, 20 ต้องจับคู่ตรงตัว ไม่แปลงเป็นตัวเลขหรือค้นบางส่วน
- ซื้อ Kit/หลายชิ้นบิลเดียวไม่ใช่ซื้อเสื้อซ้ำ ผู้ยังไม่ครบ 60 วันไม่เข้าฐาน
- การตามหลังซื้อเป็นการจำลองบนเครื่องและยินยอมได้โดยสมัครใจ
