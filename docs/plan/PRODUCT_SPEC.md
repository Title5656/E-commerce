# ข้อกำหนดต้นแบบ MONO V6

ปรับตาม MONO-V6-prototype-plan วันที่ 22 พฤศจิกายน 2569 เอกสารวิชาและรายงานต้นฉบับเก็บบนเครื่อง

## ผู้ใช้และเส้นทาง

ร้านเสื้อยืดและโปโลออนไลน์ เริ่มประชาสัมพันธ์ที่มหิดล ศาลายาและรับผู้ซื้อทั่วประเทศ ซื้อเสื้อตรงได้ ไม่ต้องเลือกสถาบัน ซื้อ Kit หรือเปิดหุ่น ผู้รับ ชำระเงิน จัดส่งและการติดตามเป็นการจำลองบนเครื่อง

| Route | ผลที่ผู้ใช้ต้องทำได้ |
|---|---|
| `#/` | ซื้อเสื้อเป็นทางเข้าหลัก มี Kit และ Fit-Twin เป็นตัวช่วย |
| `#/shop`, `#/product/:id` | กรองเสื้อยืด/โปโล ค้นชื่อหรือรหัสผ้าตรงตัว ดูราคาและตาราง เลือกไซซ์ซื้อ |
| `#/kit`, `#/passport` | Fabric Kit และคู่มือผ้าหกรหัส เชื่อมกลับเสื้อตรงรุ่น |
| `#/studio?product=polo-tc-micro&size=M&color=white` | หุ่นทั้งหกรุ่น เลือกไซซ์ หมุน ปรับสัดส่วน บันทึก/ลบ และกลับสินค้ารุ่น/ไซซ์เดิม |
| `#/cart`, `#/checkout/purchase`, `#/checkout/kit` | ตรวจยอด กรอกโค้ดและยืนยัน ชื่อ route checkout/passport เดิมยังเปิด Kit ได้ |
| `#/orders`, `#/order/:id` | ใบยืนยัน snapshot เปิดใบแนบ Kit จำลองรับเสื้อ เลือกตัวพอดี สมัคร/ถอนติดตาม |
| `#/insights` | ตัวชี้วัดจริงจากรายการเดโมในเครื่องและลิงก์ตัวอย่าง Facebook/TikTok |
| `#/privacy` | อธิบายการเก็บข้อมูลและล้างเฉพาะข้อมูลร้าน |
| `#/trial-box`, `#/trials`, `#/trials/:id`, `#/checkout/trial` | เปิดประวัติที่ยังใช้งานได้ ไม่มีธุรกรรมบริการเดิม |

สินค้า ID เดิมที่เลิกขายเปิดข้อความพร้อมทางไปคอลเลกชันใหม่ ประวัติเดิมยังเปิดใบยืนยันได้

## Kit และธุรกรรม

- Fabric Kit 99 บาท ผ้าขาว 6 รหัส รหัสละ 1 ชิ้น ขนาด 10 × 10 ซม. เก็บ Kit ไว้ได้
- รูปแบบ Kit เป็นการ์ดผ้าแบนคล้องห่วงโซ่ มีผ้าตรงกลางและปกกระดาษคราฟต์สีน้ำตาลป้องกันหน้า–หลัง ภาพแนวคิด AI มุมสามมิติใช้ WebP แบบ responsive ไม่เพิ่ม renderer/โมเดลเคลื่อนไหวบนหน้า Kit
- ภาพตัวอย่างผ้าทั้งหกรหัสใช้ AI แนวภาพถ่ายระยะใกล้ให้เห็นเส้นใยและลายถัก แยกเจอร์ซีย์กับจูติ ขนาด WebP 800 × 480 แบบ lazy/async กำกับเป็นภาพจำลองและให้ตรวจผ้าจริงก่อนสรุปสเปก
- ซื้อ Kit สำเร็จออกโค้ดบนใบแนบหนึ่งใบ ลดค่าเสื้อ 99 บาท ไม่มีขั้นต่ำ ใช้หนึ่งครั้ง หนึ่งโค้ดต่อรายการซื้อเสื้อ ไม่ใช้ลด Kit ไม่ประกาศวันหมดอายุหรือการซ้อนโค้ดที่แผนไม่ได้ระบุ
- เสื้อ 350/390/490 บาทใช้โค้ดแล้วจ่าย 251/291/391 บาท ตัวอย่าง Kit 99 + โปโลหลังลด 391 รวมสองรายการ 490 บาท
- ค่าส่งลูกค้า 0 บาท ร้านออกค่าใช้จ่าย แยกพัสดุ Kit กับเสื้อ เสื้อแต่ละ variant ซื้อ 1–9 ตัว
- UI แสดงบาท กฎและ storage ใช้จำนวนเต็มสตางค์ แสดงยอดก่อนลด ส่วนลดและยอดจ่ายทั้ง checkout/ใบยืนยัน
- เก็บ snapshot ชื่อ รหัสผ้า สี ไซซ์ ขนาด ล็อต ราคา ส่วนลด และที่มาลิงก์ ไม่คำนวณใบเก่าจาก catalog ปัจจุบัน
- ยืนยัน request เดิมคืนใบเดิม ไม่ออกโค้ดหรือตัดสิทธิ์ซ้ำ อ่าน storage ล่าสุดภายใต้ Web Lock ก่อน mutation และอัปเดต UI เมื่ออีกแท็บเปลี่ยนข้อมูล
- ย้ายประวัติ/สิทธิ์ใช้แล้วและยังว่างจาก v1 ครั้งเดียว นำสินค้าเลิกขายออกจากตะกร้าพร้อมแจ้ง คงโปรไฟล์ที่ใช้ได้และประวัติบริการเก่าเพื่ออ้างอิง

## Fit-Twin

เมนูหลักติดขอบบนด้วย CSS sticky ทั้งมือถือและเดสก์ท็อป เว้นระยะส่วนสรุปยอด หุ่นและตำแหน่ง scroll ให้ไม่ถูกเมนูบัง

ทั้งหกรุ่นใช้ตารางเดียวกับหน้าสินค้า ทรงเสื้อยืดคอกลมและโปโลคอปกแขนสั้น ปรับส่วนสูง/ไหล่/รอบอก/เอว/ขาได้ ค่าเริ่มต้น 170/44/96/78/82 ซม. ช่วง 150–190 / 38–54 / 80–125 / 65–115 / 70–105

สูตรระยะเผื่อ = รอบอกเสื้อ − รอบอกหุ่น น้อยกว่า 6 แน่น, 6–14 พอดี, มากกว่า 14 โคร่ง แนะนำไซซ์พอดีที่ใกล้ระยะเผื่อ 10 ซม. หากเสมอเลือกเล็กกว่า สูตรนี้ไม่รับรองช่วงไหล่หรือการหดหลังซัก หากวาด 3D ไม่ได้ใช้ภาพสินค้าและตารางแทน

วิธีวัดเสื้อตัวโปรด: วางราบ วัดรักแร้ถึงรักแร้คูณสอง เทียบรอบอกเสื้อสำเร็จ วัดจากจุดสูงสุดของไหล่ถึงชายเสื้อเพื่อเทียบความยาว แยกจากค่ารอบอกหุ่นชัดเจน

## หลังซื้อและตัวชี้วัด

เก็บ `channel` = direct/facebook/tiktok และ `placement` = direct/public-page/salaya-group ตามที่มาของลิงก์ แม้แชร์ต่อ ไม่ใช้อนุมานที่อยู่ผู้ซื้อ ใช้ attribution ใน visit ของแท็บจนมีลิงก์ระบุแหล่งใหม่

จำลองได้รับเสื้อพร้อมวัน เลือกเสื้อตัวที่ใส่พอดีเพื่อเริ่มแนะนำรุ่นถัดไปจากขนาดและผ้าที่ชอบ สมัคร/ถอนติดตาม LINE OA ได้โดยสมัครใจ ไม่ส่งข้อความจริง กลับมาซื้อเองได้เสมอ

- อัตราใช้โค้ด = สิทธิ์ที่ใช้ / Kit ที่ขาย
- อัตราซื้อซ้ำ = คนที่ซื้อเสื้อบิลที่สองภายใน 60 วันหลังรับเสื้อตัวแรก / คนที่รับเสื้อตัวแรกและสังเกตครบ 60 วัน
- นับต่อคนและ distinct order ไม่ใช้จำนวนตัว เสื้อสองตัวบิลเดียวหรือ Kit ตามด้วยเสื้อตัวแรกไม่ใช่ซื้อเสื้อซ้ำ ไม่เอาคนยังไม่ครบช่วงเข้าตัวหาร หากไม่มีฐานแสดง “ยังไม่มีผู้ติดตามครบ 60 วัน”
- หนึ่งเบราว์เซอร์แทนลูกค้าสมมติหนึ่งคน ชุดทดสอบแยกกรณีลูกค้าหลายคน ไม่เติมสมมติฐานยอดขายจากรายงานลงข้อมูลร้าน
