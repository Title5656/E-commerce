# MONO

ร้านเสื้อผ้าโทนธรรมชาติ เลือกสี เทียบไซซ์กับหุ่น 3D หรือจัดกล่องลองที่บ้านได้ในเบราว์เซอร์

[เปิดหน้าร้าน](https://title5656.github.io/E-commerce/) · [เปิดชุดทดสอบ](https://title5656.github.io/E-commerce/tests.html)

เปิด `index.html` เพื่อดูหน้าร้าน เปิด `tests.html` เพื่อทดสอบกติกา ใช้ GitHub Pages จากรากของ `main` เพื่อให้การบันทึกข้ามการรีเฟรชทำงานตาม origin ของเว็บ

| ทดลอง | เริ่มที่ |
|---|---|
| ซื้อเสื้อผ้า | เลือกซื้อ → เลือกสี/ไซส์ → ตะกร้า |
| สมุดผ้า | Fabric Passport → สั่งสมุด → ใช้เครดิตเมื่อซื้อเสื้อผ้าครบ 499 บาท |
| เทียบไซส์ | ห้องลอง 3D → เลือกสีและไซซ์ → ปรับสัดส่วน หมุนดูทรง และบันทึก |
| กล่องลอง | เพิ่มกล่องลอง → เลือกจุดคืน → รับของจำลอง → เก็บ/คืน |

เว็บใช้ไฟล์ใน repo ทั้งหมดและฟอนต์ระบบ ราคาในเว็บแสดงเป็นบาท การยืนยันใช้ข้อมูลตัวอย่างและไม่มีการเรียกเก็บเงินจริง

เริ่มทำงานต่อจาก [AGENTS.md](AGENTS.md) และ [TASKS.md](TASKS.md)
