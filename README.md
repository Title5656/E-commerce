# MONO V6

ต้นแบบร้านเสื้อยืดและโปโล 6 รุ่น เลือกซื้อได้โดยตรง มี Fabric Kit และ Fit-Twin ช่วยเลือกผ้าและไซซ์ ส่งทั่วประเทศ

[หน้าร้าน GitHub Pages](https://title5656.github.io/E-commerce/)

ลิงก์ Pages แสดงรุ่นที่เผยแพร่ล่าสุด การแก้ไขในเครื่องต้อง push และรอ deployment ก่อนปรากฏบนเว็บ

เปิด `index.html` เพื่อทดลอง และ `tests.html` เพื่อตรวจสูตร/ธุรกรรมโดยไม่กระทบข้อมูลร้าน เว็บใช้ HTML/CSS/JavaScript ฟอนต์ระบบและ SVG/WebP ใน repo ไม่มีขั้นตอน build แพ็กเกจหรือ API

| ทดลอง | เส้นทาง |
|---|---|
| ซื้อเสื้อตรง | เลือกซื้อเสื้อ → รุ่น/ไซซ์ → ตะกร้า → ยืนยัน |
| ซื้อ Kit | Fabric Kit ฿99 → ยืนยัน → เปิดใบแนบจำลองเพื่ออ่านโค้ด |
| ใช้โค้ด | เลือกเสื้อ → checkout → กรอกโค้ด → ตรวจยอด → ยืนยัน ลด ฿99 ไม่มีขั้นต่ำ เสื้อ ฿350/390/490 เหลือ ฿251/291/391 |
| เทียบไซซ์ | สินค้า → Fit-Twin → เปลี่ยนไซซ์ → ดูเสื้อตัวนี้ กลับรุ่นและไซซ์เดิม |
| ซื้อซ้ำ | ใบสั่งซื้อ → จำลองได้รับเสื้อ → เลือกตัวใส่พอดี → ดูรุ่นแนะนำ → ซื้อบิลใหม่ |
| ช่องทางและผล | ท้ายเว็บ → ผลสาธิตและช่องทาง → ลิงก์ Facebook/TikTok และวิธีนับ 60 วัน |

ผ้ารหัส `1`, `0`, `2.1`, `2.2`, `20`, `24` ค้นแบบตรงรหัส Kit มีผ้าขาวรหัสละหนึ่งชิ้น 10 × 10 ซม. เก็บชุดไว้ได้ ร้านออกค่าส่ง Kit กับเสื้อแยกกัน หุ่นรองรับทั้งหกรุ่นและมีตารางเมื่อแสดง 3D ไม่ได้

ภาพเสื้อทั้ง 6 รุ่นเป็นภาพสร้างด้วย AI แนวถ่ายสินค้าสตูดิโอ ดู [ที่มาภาพและ prompt](assets/products/IMAGE_SOURCES.md) สี ขนาดและน้ำหนักผ้าเป็นข้อมูลสาธิต ต้องยืนยันกับโรงงานก่อนขายจริง ผู้รับ การชำระเงิน จัดส่งและ LINE OA เป็นการจำลองบนเครื่อง ไม่มีการเก็บเงินจริงหรือส่งข้อความ

ข้อมูล v1 ย้ายไป `mono.v2` ครั้งเดียว คงประวัติราคา/สินค้า/สิทธิ์เดิมและโปรไฟล์ที่ใช้ได้ สินค้าที่เลิกขายออกจากตะกร้าพร้อมแจ้ง ส่วนลิงก์บริการเก่าเปิดหน้าประวัติได้ การใช้หลายแท็บบน HTTPS ใช้ Web Locks ใน Edge/Chrome
