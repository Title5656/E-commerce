# บันทึกการตัดสินใจ

| เรื่อง | สถานะและเหตุผล |
|---|---|
| ขั้นต่ำเครดิต 499 บาท | ผู้ใช้เลือก ทั้ง 99 บาทและต้นทุนเป็นตัวเลขเดโม |
| มัดจำชิ้นแพงสุดและแสดงยอดเสี่ยง | ผู้ใช้เลือก กล่องมูลค่า 1,470 บาทแสดงยอดเสี่ยง 880 บาท |
| งบ 0 บาทและ GitHub Pages | ผู้ใช้กำหนด ใช้ native HTML/CSS/JS ไม่มีขั้นตอน build |
| ไฟล์เว็บอยู่ที่ราก repo | ใช้ราก checkout เดียวกับ Pages ลดการคัดลอกไฟล์ระหว่างเครื่องกับ publishing source |
| ชื่อ WARIN และภาพต้นฉบับ | ใช้ชื่อทำงานและ SVG เพราะ workspace ไม่มีภาพเสื้อของทีม |
| แนะนำไซส์จากรอบอก 2 รุ่น | ค่า 6–14 ซม. และมิติของสินค้าคือสมมติฐานเดโม |
| รายงานและงานนำเสนอ | ผู้ใช้ขอพักไว้จนต้นแบบเสร็จและเริ่มใหม่ในแชตถัดไป |
