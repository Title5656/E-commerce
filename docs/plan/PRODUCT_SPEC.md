# ข้อกำหนดต้นแบบ WARIN

## ผู้ใช้และเส้นทาง

ผู้ซื้อเสื้อพื้นฐานที่อยากรู้สัมผัสผ้า เลือกไซส์ และลองที่บ้าน ใช้ภาษาไทย ราคาเป็นบาท และป้ายเดโมปรากฏตลอดเส้นทาง สำรวจผ้าและเทียบไซส์ได้ก่อนเริ่มธุรกรรม

| Route | ผลที่ผู้ใช้ต้องทำได้ |
|---|---|
| `#/` | เข้าร้านหรือ Studio เห็นสินค้าแนะนำและเปิดแต่ละบริการได้ |
| `#/shop`, `#/product/:id` | กรองประเภทและสี เห็นรูปตามสี ข้อมูลผ้า ตารางไซส์ และเลือกรายการซื้อ/ลองแยกกัน |
| `#/passport` | อ่านการ์ดผ้า 6 ชนิด เห็นเงื่อนไข 99/499 บาท และไปยืนยันสมุด |
| `#/studio?product=tee-heavy` | เลือกเสื้อ/ไซส์ S–XL ปรับหุ่น 5 มิติ อ่านคำแนะนำ บันทึกหรือลบโปรไฟล์ |
| `#/cart`, `#/trial-box` | เพิ่มลดจำนวนซื้อ ดู 3 ช่องลอง เลือกคาเฟ่ใน checkout |
| `#/checkout/:mode` | `purchase`, `passport`, `trial` ใช้ที่อยู่สาธิตโดยอัตโนมัติ แสดงยอดก่อนยืนยัน |
| `#/orders`, `#/order/:id`, `#/trials`, `#/trials/:id` | เปิดรายการเดิม รับของ เลือกเก็บ/คืน ดูหลักฐานและยอดปิดกล่อง |
| `#/privacy` | อ่านวิธีเก็บข้อมูล และรีเซ็ตเฉพาะข้อมูลต้นแบบ |

## กติกาธุรกรรม

- ซื้อปกติและกล่องลองเป็นตะกร้าคนละชุด ค่าส่งเดโมศูนย์บาท สินค้าปกติรายการละ 1–9 ชิ้น กล่องลองไม่เกิน 3 ชิ้น
- สมุดราคา 99 บาท ออกเครดิต 99 บาท 1 ใบต่อสมุด เลือกใช้ได้ 1 ใบต่อออเดอร์เสื้อผ้าปกติที่ยอดก่อนหักอย่างน้อย 499 บาท ใช้เครดิตเก่าสุดที่ยังว่าง ตัดสิทธิ์พร้อมยืนยันออเดอร์
- กล่องลองจ่ายมัดจำเท่าชิ้นแพงสุด แสดงยอดเสี่ยงเต็มลบมัดจำ ชุดเดโม 390+490+590 บาท ได้ 1,470/590/880 บาท
- เริ่ม 72 ชั่วโมงตอนรับของ กำหนดเก็บหรือคืนทีละชิ้น คำนวณส่วนต่างจากยอดเก็บลบมัดจำ กล่องมีของคืนต้องตรวจผ่านก่อนออกใบปิดยอด เกิดปัญหาแล้วให้พักปิดยอด
- Fit-Twin รุ่น tee-heavy และ shirt-linen ใช้รอบอกเท่านั้นในการจำแนก น้อยกว่า 6 = แน่น, 6–14 = พอดี, มากกว่า 14 = โคร่ง แนะนำไซส์พอดีที่ใกล้ช่วงเผื่อ 10 ซม.ที่สุด ถ้าเสมอให้เลือกเล็กกว่า ช่วงปรับภาพหุ่น 150–190 / 38–54 / 80–125 / 65–115 / 70–105 ซม. ค่าเดโม 170 / 44 / 96 / 78 / 82
- ตัวเลขและผลฟิตเป็นภาพช่วยตัดสินใจสำหรับการสาธิต ราคาจำลอง คาเฟ่จำลอง และข้อมูลผู้รับจำลองปรากฏก่อนกดยืนยัน
