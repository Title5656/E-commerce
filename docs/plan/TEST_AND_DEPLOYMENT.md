# ทดสอบและเผยแพร่

เปิด `tests.html` ในเบราว์เซอร์ ตรวจจำนวนผ่าน/ตกและค่าที่คาดไว้ ชุดทดสอบใช้สถานะของตัวเอง และต้องไม่เปลี่ยนข้อมูลในร้าน

| ตรวจจากหน้าร้าน | ผลที่คาด |
|---|---|
| ซื้อเสื้อคอตตอนหนา 1 ชิ้น | 390 บาท คลิกยืนยันซ้ำหรือ refresh แล้วคงใบเดิม |
| ซื้อสมุด จากนั้นซื้อกางเกงทวิลล์ | สมุด 99 บาท ได้เครดิต ซื้อ 499 บาทโดยใช้เครดิตจ่าย 400 บาท |
| Studio ตั้งอก 96 แล้วเลือกเสื้อยืดหนา | S แน่น, M พอดีระยะเผื่อ 10, L โคร่ง แนะนำ M กลับหน้าสินค้าแล้วคำแนะนำตรงกัน |
| ทดลอง 390+490+590 | เต็ม 1,470 บาท มัดจำ 590 บาท คงความเสี่ยง 880 บาท เก็บโปโลและคืนสองชิ้นแล้วปิดยอดคืน 100 บาท |
| ทดสอบเวลาและปัญหา | กล่องเลยกำหนดยังเปิดขั้นตอนคืนได้ กรณีเสียหายหรือสูญหายพักปิดยอด |
| ทดสอบอุปกรณ์ | หน้า 390 และ 1,440 พิกเซล ลิงก์ตรง รูปและทรัพยากรเปิดใต้ path ของ repo แท็บส่วนตัวเปิดได้ รีเซ็ตแล้วกลับมาเริ่มใหม่ได้ |

GitHub Pages ใช้แหล่ง `main` / `/(root)` เผยแพร่ static จาก `index.html` และไฟล์ `.nojekyll` ตรวจหน้า Settings → Pages และ URL ที่แสดงในนั้น หลังเปลี่ยนไฟล์ให้เปิด URL สาธารณะใหม่และทำสี่เส้นทาง รุ่นที่เผยแพร่ต้องโหลดทรัพยากรของโครงการจาก origin เดียวกัน
